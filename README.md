# Arodan

Errands, delivery and e-commerce for Magodo Phase 2, Lagos.

| Folder | App | Status |
| --- | --- | --- |
| [`customer-app/`](customer-app) | Customer mobile app (Expo / React Native) | Works offline (demo) or with the server |
| [`server/`](server) | API server (Node.js): SMS sign-in, catalogue, orders, rider jobs, merchants | Ready to deploy |
| [`db/`](db) | PostgreSQL schema, security rules, server-side pricing, seed data | Ready |
| [`rider-app/`](rider-app) | Rider app (Expo / React Native): jobs, navigation, live location, proof of delivery, earnings | Works offline (demo) or with the server |
| [`merchant-app/`](merchant-app) | B2B merchant app: shop sign-up, products with photos and stock, orders to prepare for pickup, sales | Works offline (demo) or with the server |

See the README in [`customer-app/`](customer-app/README.md), [`rider-app/`](rider-app/README.md) and [`merchant-app/`](merchant-app/README.md) to run the apps on your phone, and [`server/README.md`](server/README.md) to run the backend.
