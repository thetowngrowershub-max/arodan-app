# Arodan

Errands, delivery and e-commerce for Magodo Phase 2, Lagos.

| Folder | App | Status |
| --- | --- | --- |
| [`app/`](app) | **The Arodan app** (Expo / React Native) for shoppers, riders and merchants. Riding and selling open after Arodan approves the application | Works offline (demo) or with the server |
| [`server/`](server) | API server (Node.js): SMS sign-in, catalogue, orders, rider jobs, merchants | Ready to deploy |
| [`db/`](db) | PostgreSQL schema, security rules, server-side pricing, seed data | Ready |

See [`app/README.md`](app/README.md) to run the app on your phone, and [`server/README.md`](server/README.md) to run the backend.
